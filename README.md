# Student Record Management System

## About

A menu-driven C application that uses a **Singly Linked List** and file handling to manage student records.

## Features

- Add and delete student records
- Display and modify student details
- Search records by roll number, name, or percentage
- Sort by name or percentage
- Save and load student records

## Technologies

C, Singly Linked List, Structures, Pointers, Dynamic Memory Allocation, File Handling, GCC, Linux.
